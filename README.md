# Croqui de Sinistro

App de campo para amarração e croqui de sinistros de trânsito. Funciona offline depois de instalado.

Publicado com GitHub Pages: Settings → Pages → Branch `main` / pasta `/ (root)`.
Para atualizar: substitua `index.html` e troque `croqui-v1` em `sw.js` por `croqui-v2`, `croqui-v3`...
